# Spec: UI — Tipos TRIMESTRAL y SEMESTRAL

## Diálogo "Abrir Nuevo Período"

El Select de tipo MUST incluir:

```tsx
<SelectItem value="DIARIO">Diario</SelectItem>
<SelectItem value="MENSUAL">Mensual</SelectItem>
<SelectItem value="TRIMESTRAL">Trimestral</SelectItem>
<SelectItem value="SEMESTRAL">Semestral</SelectItem>
<SelectItem value="ANUAL">Anual</SelectItem>
```

## Labels en Tabla

El mapeo `TIPO_LABELS` MUST incluir:

```typescript
const TIPO_LABELS: Record<string, string> = {
  DIARIO: "Diario",
  MENSUAL: "Mensual",
  TRIMESTRAL: "Trimestral",
  SEMESTRAL: "Semestral",

```

Este mapeo se usa en:
- `periodos-page-client.tsx` (columna Tipo)
- `abrir-periodo-dialog.tsx` (no aplica, usa `TipoPeriodo` enum directamente)
- `cerrar-periodo-dialog.tsx` (badge de tipo)
- `reabrir-periodo-dialog.tsx` (badge de tipo)

## PeriodoActivoIndicator (Header)

```typescript
function formatPeriodoLabel(fechaInicio: Date, fechaFin: Date, tipo: string): string {
  if (tipo === 'DIARIO') return `${fechaInicio.getDate()} ${MESES[fechaInicio.getMonth()]} ${fechaInicio.getFullYear()}`
  if (tipo === 'MENSUAL') return `${MESES[fechaInicio.getMonth()]} ${fechaInicio.getFullYear()}`
  // NUEVO:
  if (tipo === 'TRIMESTRAL') {
    const trim = Math.ceil((fechaInicio.getMonth() + 1) / 3)
    return `T${trim} ${fechaInicio.getFullYear()}`
  }
  if (tipo === 'SEMESTRAL') {
    const sem = fechaInicio.getMonth() < 6 ? 'S1' : 'S2'
    return `${sem} ${fechaInicio.getFullYear()}`
  }
  return `${fechaInicio.getFullYear()}`
}
```
