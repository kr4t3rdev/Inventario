# GEO Remediation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Raise FinanceMDM's SEO and GEO readiness by fixing the highest-risk public-site gaps first: metadata, schema, crawl guidance, evidence quality, and documentation freshness.

**Architecture:** Centralize public-site SEO data and schema generation in a small `src/lib/seo/` module, then wire it into the root layout, landing page, sitemap/robots handlers, and docs routes. Keep the first phase minimal and measurable: ship only what improves semantic clarity and crawlability without redesigning the landing or adding net-new marketing pages.

**Tech Stack:** Next.js 16 App Router, TypeScript, React 19, Vitest, ESLint

## Notes for the implementer

- Do not add schema just because it exists. Ship only schema backed by visible content.
- Do not preserve risky numeric claims unless there is evidence already available in the repo or from the product owner.
- Keep client/server boundaries clean: metadata and JSON-LD should be server-driven; animated UI can remain client-side.
- The docs route already has `generateStaticParams`; do not waste time re-solving solved crawlability.
- If the real production domain is unknown, stop and get it before finalizing `metadataBase`, canonical URLs, sitemap, and robots.
